# RAG 评测报告

## 1. 评测集

| 项 | 说明 |
|---|---|
| 规模 | 60 个问题（抽样自 CSL 摘要，seed=2026） |
| 构造方式 | 从 CSL 39.6 万篇摘要中筛长度 120–400 字的论文，由本地 Qwen3-4B 为每篇生成一个"能且只能由该摘要回答"的问题 |
| 标注 | gold = 该摘要所属 `doc_id`（自动生成，无需人工） |
| 产物 | `retrieval/data/qa_eval.jsonl` |

> 说明：这是**合成评测集**，问题由模型根据摘要生成，天然偏向"摘要里能找到答案"，
> 因此指标偏乐观；它衡量的是检索链路与引用链路的正确性，而非开放式问答的绝对质量。

## 2. 结果

| 指标 | 数值 | 含义 |
|---|---|---|
| retrieval_hit@5 | **0.950** | top-5 中命中 gold 摘要的比例 |
| retrieval_hit@10 | **0.950** | top-10 命中率（说明 top-5 之后基本没有新增命中） |
| citation_hit@5 | **0.950** | 完整问答链路中，引用列表包含 gold 摘要的比例 |
| 平均检索耗时 | 840 ms | 双路召回（100 候选）+ 重排 |
| 平均问答耗时 | 1.9 s | 检索 + 生成（答案较短时） |

`citation_hit@5 = retrieval_hit@5 = 0.95` — 说明**生成层没有丢失检索结果**，引用与检索一致。

## 3. 典型失败案例

- 问题："工商部门在市场经济形势下面临哪些监管挑战？"（gold: csl-321305，标题《扎实推进业务建设不断提高履职效能》）
  检索返回了同一主题的其他文献，gold 未进 top-5。
- 原因分析：问题较泛，摘要主题与问题只有间接关联；这类"泛问题"是合成评测集的固有噪声。

## 4. 复现

```bash
conda activate rag
cd retrieval
python build_qa_eval.py --n 60     # 生成评测集
python eval_rag.py --ask-n 20      # 检索命中 + 引用命中
```

## 5. 后续可加强

1. 人工标注 50–100 条真实问题（非合成），评估开放式问答的忠实度（答案是否被引用支撑）。
2. 对答案做 LLM-as-judge：检查是否存在"引用不支撑结论"的幻觉。
3. 统计不同学科/摘要长度下的检索命中率，定位薄弱环节。
